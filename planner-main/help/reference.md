# Reference image

## Loading and configuring

| | |
|---:|:---|
| `B` | Toggle reference image visibility. |
| `Alt + B` | Unlock the reference image for editing. |

There are a few ways to load up a reference image for tracing in Planner.

- On the **View** menu, click **Reference image**
- Press `B` on the keyboard
- Enable **Reference Image** on the **World** tab.

A reference image sits behind the drawing and provides a guide for tracing an
existing plan. Adjust its position, size, rotation and opacity to align it with
the canvas, or calibrate its scale against a known distance.

Once an image is loaded, it can be toggled on and off through the **View** menu,
by pressing `B` or toggling the checkbox on the **World** tab.

If you click away from the image after loading it, it will be locked from editing.
To enable it again, press `Alt + B`, click the entry in the **View** menu, or click the **Reference image** entry on the
**World** tab without toggling it.

## Calibrate scale

Calibrate scale lets you use a known distance on your reference image to size the
image correctly.

Open the reference image properties with `Alt + B` and choose **Calibrate Scale**. You
can then choose two end points for the distance you want measured. Press `Enter` when done,
enter the known distance and the reference image will scale itself to fit.

## Saving

The reference image is embedded in your project when you save. This means the original
image file is not needed when opening the saved project on another device.
