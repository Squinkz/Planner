# Toolbar buttons

## Sidebar tabs

| | | | |
|:---:|---:|:---|:---|
| ![Build tab](images/icons/build.png) | `1` | **Build tab** | Setup the **Wall Tool** and place architectural **Objects**. |
| ![Furnish tab](images/icons/furnish.png) | `2` | **Furnish tab** | Search for and place **Furnishings**. |
| ![World tab](images/icons/world.png) | `3` | **World tab** | Enable or disable visibility for object types, and configure the [**Reference image**](reference.md). |
| ![Export tab](images/icons/export.png) | `4` | **Export tab** | Export your plan as a bitmap or vector file. |

## Toolbar

| | | | |
|:---:|---:|:---|:---|
| ![Snapping](images/icons/snap.png) | `Alt` | **Snapping** | Enable or disable snapping. Hold `Alt` to toggle this setting. |
| ![Snapping Options](images/icons/snap_opt.png) | | **Snapping Options** | Configure which objects form snapping targets. |
| | | |
| ![Connected Points](images/icons/con_vert.png) | | **Connected Points** | Moving a wall or its control points also moves connected control points and control points that intersect the wall’s body. |
| ![Connected Objects](images/icons/con_obj.png) | | **Connected Objects** | Objects of the same class move together as a whole when their bodies touch or overlap. |
| | | | |
| ![Group Toggle](images/icons/group_toggle.gif) | `Ctrl + Tab` | **Group Toggle** | Enable or disable grouped selection. |
| ![Add to Group](images/icons/group_add.png) | `Ctrl + G` | **Add to Group** | Create or add to a group using the current selection. |
| ![Remove from Group](images/icons/group_remove.png) | `Alt + G` | **Remove from Group** | Remove the current selection from a group. |
| | | | |
| ![Hide Selected](images/icons/hide_sel.png) | `H` | **Hide Selected** | Temporarily hide selected objects. |
| ![Hide Unselected](images/icons/hide_unsel.png) | `Ctrl + H` | **Hide Unselected** | Temporarily hide unselected objects. |
| ![Unhide All](images/icons/unhide.png) | `Alt + H` | **Unhide All** | Restore all temporarily hidden objects. |
| | | | |
| ![Global/Local Transforms](images/icons/transforms.gif) | `Tab` | **Transform Toggle** | Use the canvas axes for global transforms or the object’s orientation for local transforms. |
