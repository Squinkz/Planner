# Keyboard and mouse shortcuts

Canvas shortcuts apply while the canvas has focus. Text editors retain their
own typing, selection and clipboard shortcuts.

## Navigation and help

| | |
|---:|---|
| `F1` | Open Help.
| `1 / 2 / 3 / 4` | Open **Build** / **Furnish** / **World** / **Export**. |
| `F` | Toggle the sidebar. |
| `Middle-drag` | Pan. |
| `Mouse wheel` | Zoom around the pointer. |
|  `Double-click` | Reset the camera. |

## Reference image

| | | |
|---:|:---:|---|
| `B` | *no reference imaged loaded* | Load a reference image. |
| `B` | *reference imaged loaded* | Toggle reference image visibility. |
| `Alt + B` | *reference imaged loaded* | Adjust reference image. |

## Projects and history

| | |
|---:|---|
| `Ctrl + N` | New project from the startup template. |
| `Ctrl + O` | Open a project. |
| `Ctrl + S` | Save. |
| `Ctrl + Shift + S` | Save As. |
| `Ctrl + W` | Close the project. |
| `Ctrl + Z` | Undo. |
| `Ctrl + Shift + Z` | Redo. |
| `Alt + P` | Check plan for geometry issues, missing assets and other problems. |

## Selection, clipboard and grouping

| | |
|---:|---|
| `Left-click` | Select an object or control point. |
| `Left-drag`| Box-select. |
| `Shift + box-select` | Add objects to the selection. |
| `Ctrl + box-select` | Remove objects from the selection. |
| `Shift + click` | Add to selection. |
| `Ctrl + click` | Remove from selection. |
| `Ctrl + A` | Select all visible objects. |
| `Ctrl + Shift + A` | Deselect all. |
| `Delete` | Delete the selection. |
| `Ctrl + X / C / V` | Cut / Copy / Paste. |
| `Ctrl + Shift + V` | Paste at the copied coordinates. |
| `G` | Toggle the grid. |
| `Ctrl + G` | Group the selected objects together. |
| `Alt + G` | Remove selected objects from their groups. |
| `H` | Hide selected objects or groups. |
| `Ctrl + H` | Hide unselected objects. |
| `Alt + H` | Restore hidden objects, subject to visibility filters. |
| `T` | Open **Transform** tool. |

## Moving and duplication

| | | |
|---:|:---:|---|
| `Drag` | *selection* | Move the selection. |
| `Shift + drag` | | Duplicate and move. |
| `Arrow keys` | | Nudge one visible minor grid interval. |
| `Shift + Arrow` | | Duplicate and nudge. |
| `Shift + drag` | *control point* | Extend a supported segment from its starting point. |
| `Ctrl + drag` | *object* | Constrain translation to an axis. |
| `Ctrl + drag` | *control point* | Constrain movement to 15-degree axes. |
| `Mouse wheel` | *while `Ctrl + drag` a control point* | Switch the axis origin between endpoints. |
| `Alt` | | Temporarily invert the snapping toggle. |
| `Escape` | *during a move* | Cancel and restore its starting state. |
| `Right-click` | *during a move* | Cancel and restore its starting state. |

## Drawing and placement

| | | |
|---:|:---:|---|
| `Right-drag` | | Draw a wall. |
| `Left-click` | *while `Right-drag`* | Cancel. |
| `Ctrl + right-drag` | | Draw at 15-degree increments. |
| `Right-click` | | Open the context menu. |
| `Q / W` | | Choose a thinner / thicker new-wall preset. |
| `D` / `S` | *hold* | Repeated door / window placement. |
| `Mouse wheel` | *while holding `D` or `S`* | Cycle opening types. |
| `Ctrl` | *while placing window/door* | Choose orientation. |
| `Ctrl` | *while drawing rectangle/polygon* | Constrain proportions. |
| `Shift` | *while drawing rectangle/polygon* | Expand from center. |
| `Mouse wheel` | *while drawing polygon* | Change number of segments. |
| `Right-click` | *while performing action* | Cancel. |

## Handles and fields

| | | |
|---:|:---:|---|
| `Left-click` | *on a selection* | Switch resize/rotation modes. |
| `Drag` | *corner resize handle* | Preserve proportions. |
| `Drag` | *side resize handle* | Scale a single dimension. |
| `Shift` | *resize* | Resize from the center. |
| `Shift` | *rotation* | Duplicate and rotate. |
| `Drag` | *rotation pivot* | Choose the rotation origin. |
| `Double-click` | *rotation pivot* | Reset to center. |
| `Left-click` | *numeric field* | Enter a value. |
| `Drag` | *numeric field* | Adjust. |
| `Alt + Drag` | *numeric field* | Fine control. |
| `Enter` | | Commit input. |
| `Escape` | *drag* | Cancel. |
| `M` | | Toggle measurements. |
