## Make your first plan

1. **File > New Project**: start from your startup template.
2. **Build** tab, **Wall Tool**: set a wall thickness and material, hold `Right-mouse` and `Drag` on the canvas to draw a wall.
3. **Build** tab, **Objects** panel: drag doors and windows and drop them onto placed walls, or use the keyboard shortcuts `D` and `S`. Add stairs, counters or other objects from the **Objects** panel.
4. **Furnish** tab: search for an object and drop it onto the plan. Use the quicksearch menu with `Space` for quick placement.
5. **File > Save Project**: save your plan.
6. **Export** tab: choose a format, crop and scale, then press **Export**.
